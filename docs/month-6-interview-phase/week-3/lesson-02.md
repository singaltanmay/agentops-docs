# FDE drill I — customer discovery role-play

**Week 3 · Build · 75 min** · Month 6 — Interview Phase

## Objective
Run a customer-discovery drill: given a two-paragraph ambiguous customer situation, conduct a 25-minute discovery (questioning a role-played stakeholder — instructor-simulated or a peer) and produce the problem restatement + the three questions that mattered most.

## Why this exists
FDE loops test ambiguity-handling live: the discovery conversation *is* the job sample. Your Month 5 brief work was solo; this drill adds the interpersonal variable — extracting constraints from someone who doesn't speak in success criteria.

## Prerequisites
Lesson 1 story bank available (you'll reach for the deployment story). Drill discipline (whole month): every drill is timed, performed unaided (no notes beyond what's stated), and scored against a rubric written *before* the drill. A drill you score yourself counts only when the rubric is mechanical enough that a stranger would score it the same — record the artefact (doc, recording, transcript) for every drill; Month 6 runs on evidence like every other month.

## Retrieval warm-up (closed-book, 8–12 min)
1. **Previous lesson (Month 6 Week 3, Lesson 1 (The story bank — P1–P4 as STAR stories with numbers)):** state its objective and its verification in one sentence each — from memory, guide closed.
2. **Spaced review (Month 6 Week 2):** one generative item — write the key command, schema, or rule from that lesson without looking.
3. **Interleaved discrimination:** one item mixing this week's pattern with its most confusable neighbour, unlabelled — name which is which and why.
4. **Prediction:** predict the output/behaviour of today's first build step before you run it. Write the prediction down.
5. Tag every answer with a confidence (0–100%) *before* checking. A miss on a prerequisite for today changes today's plan now, per the opening routine.

## Prerequisite check
Re-run the previous lesson's independent verification (Month 6 Week 3, Lesson 1 (The story bank — P1–P4 as STAR stories with numbers)) before starting. If it no longer passes, repair first and compress today's objective — never stack new work on a broken base.

## Core concept
Discovery method (from the Month 5 brief anatomy, run conversationally): current workflow + pain (their words) → cost of the pain → data reality (what exists, how messy, who owns it) → users + permissions → success in their terms → constraints (timeline, systems, politics) → the smallest valuable first deployment. Anti-patterns: pitching features mid-discovery, accepting the first problem statement, leaving without the data-reality picture.

## Build steps
Expected output is stated *before* you run each step. If you see something else, stop, classify the error (slip / execution-model / API misconception / design misconception), and check the failure notes.

### Step 1 — Pre-brief
Read the two-paragraph situation; write your discovery plan (the 7 areas + your opening question).

**Expected output:** Plan committed before the role-play starts.

### Step 2 — Run the discovery (25 min)
Role-play the stakeholder; you lead. (If solo: run it as a written dialogue, stakeholder answers drawn from the situation's implications — mark the artefact `simulated-solo`.)

**Expected output:** Transcript/notes exist; the stakeholder's constraints surfaced (count them).

### Step 3 — Restate the problem
Write the FDE restatement: problem, users, data reality, success criteria (measurable), smallest first deployment, top risk.

**Expected output:** Restatement committed; every claim traces to something the stakeholder said (highlight the lines).

### Step 4 — Score + extract
Score against the discovery rubric; name the 3 questions that unlocked the most + the area you under-explored.

**Expected output:** Score + extraction committed; under-explored area becomes Drill II's emphasis.

## Independent verification (checkpoint)
A scored discovery artefact exists with a traceable problem restatement — the FDE loop's first half, rehearsed.

## Unaided probe (closed-guide)
State your confidence (0–100%) before checking each answer.

1. Generative: the 7 discovery areas in order, unaided.
2. Prediction: which area do engineers most commonly under-explore in discovery? (Compare with your score sheet after answering.)
