# Deep build — the full timed coding set + demo environment check

**Week 2 · Deep build · ~3 hrs** · Month 6 — Interview Phase

## Objective
Run a full mock coding screen end-to-end (production rep + DSA rep + trace diagnosis, back-to-back, recorded), then verify the live Workbench demo environment end-to-end (the system you'll demo in loops must be *up*).

## Why this exists
Back-to-back stamina is a separate skill from per-rep skill, and a dead demo in a final round is an unforced error. This build tests both, early enough to fix either.

## Prerequisites
Week 2 lessons complete.

## Retrieval warm-up (closed-book, 8–12 min)
1. **Previous lesson (Month 6 Week 2, Lesson 5 (Consolidation — coding mixed gate)):** state its objective and its verification in one sentence each — from memory, guide closed.
2. **Spaced review (Month 6 Week 1):** one generative item — write the key command, schema, or rule from that lesson without looking.
3. **Interleaved discrimination:** one item mixing this week's pattern with its most confusable neighbour, unlabelled — name which is which and why.
4. **Prediction:** predict the output/behaviour of today's first build step before you run it. Write the prediction down.
5. Tag every answer with a confidence (0–100%) *before* checking. A miss on a prerequisite for today changes today's plan now, per the opening routine.

## Prerequisite check
Re-run the previous lesson's independent verification (Month 6 Week 2, Lesson 5 (Consolidation — coding mixed gate)) before starting. If it no longer passes, repair first and compress today's objective — never stack new work on a broken base.

## Core concept
Mock protocol: one sitting, screen-shaped timing, no pauses except the stated ones; self-score after (rubric), then a written retro. Demo check: the full Month 5 walkthrough (RAG answer with citations, agent task with a gate, MCP call from the second client) executed against the deployed env, timed — target: the whole story in <10 minutes of demo time.

## Build steps
Expected output is stated *before* you run each step. If you see something else, stop, classify the error (slip / execution-model / API misconception / design misconception), and check the failure notes.

### Step 1 — Mock coding screen (full)
Three parts back-to-back under screen timing.

**Expected output:** Artefacts + scores recorded; retro names the stamina effect (part 3 vs part 1 quality).

### Step 2 — Score + gap triage
Rank all open coding gaps by (loop probability × cost); top 2 get Week 3 warm-up slots.

**Expected output:** Triage committed; Week 3 warm-ups updated.

### Step 3 — Demo environment check
Run the 3-part walkthrough on the deployed env; fix what's broken (cold-start toggles, expired creds) *now*, not in Week 4.

**Expected output:** Walkthrough completes; timings recorded; fixes logged.

### Step 4 — Demo script v1
Write the 10-minute demo script (narration beats + the fallback if a call fails live).

**Expected output:** Script committed; the fallback path is a recorded run, labelled as such — never a fake 'live' moment.

## Independent verification (checkpoint)
A full mock screen is scored with a stamina note, and the demo environment + honest script are verified working.

## Unaided probe (closed-guide)
State your confidence (0–100%) before checking each answer.

1. Teach-back: the demo script's opening 90 seconds, delivered as written — does it lead with a number?
2. Generative: your top-2 coding gaps + their scheduled repairs, unaided.

## Definition of done
- [ ] All build steps completed with expected outputs matched
- [ ] Independent verification passed
- [ ] Unaided probe: majority correct *with explanations* (else this lesson's KCs are `fragile` — repair scheduled)
- [ ] System left running; checkpoint committed
- [ ] Log entry written (below) and PROGRESS.md updated

## Log entry prompt
Write your own 3 lines — *what I built / what broke and why / what I still can't do unaided* — then set this lesson's status in PROGRESS.md (`assisted` if any step was demonstrated for you, `mastered` only when the probe passed unaided).
