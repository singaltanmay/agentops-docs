# Consolidation — narrative mixed gate + applications audit

**Week 3 · Review · 60 min (light)** · Month 6 — Interview Phase

## Objective
Pass the Week 3 mixed gate (one story, one discovery segment, one plan section — drawn unseen) and audit the application pipeline: every live application mapped to a tier + the claims its résumé version makes.

## Why this exists
Applications have been running in parallel since late Month 5; this audit is the integrity checkpoint: every résumé claim must trace to an artefact (the course's founding rule, applied to the document that matters most).

## Prerequisites
Lessons 1–4 done; application tracker (wherever it lives) accessible.

## Retrieval warm-up (closed-book, 8–12 min)
1. **Previous lesson (Month 6 Week 3, Lesson 4 (Behavioural reps — the hard questions, answered from the bank)):** state its objective and its verification in one sentence each — from memory, guide closed.
2. **Spaced review (Month 6 Week 2):** one generative item — write the key command, schema, or rule from that lesson without looking.
3. **Interleaved discrimination:** one item mixing this week's pattern with its most confusable neighbour, unlabelled — name which is which and why.
4. **Prediction:** predict the output/behaviour of today's first build step before you run it. Write the prediction down.
5. Tag every answer with a confidence (0–100%) *before* checking. A miss on a prerequisite for today changes today's plan now, per the opening routine.

## Prerequisite check
Re-run the previous lesson's independent verification (Month 6 Week 3, Lesson 4 (Behavioural reps — the hard questions, answered from the bank)) before starting. If it no longer passes, repair first and compress today's objective — never stack new work on a broken base.

## Core concept
Claims audit method: line-by-line over the submitted résumé — for each bullet, name the artefact (write-up, report, run) that proves it. Any bullet without an artefact is rewritten to what the evidence supports or cut. Tier map: Tier A = roles #1–#3 at AI-native/big-tech AI teams; Tier B = FDE at labs/vendors; Stretch = frontier Research Engineer (opportunistic only).

## Build steps
Expected output is stated *before* you run each step. If you see something else, stop, classify the error (slip / execution-model / API misconception / design misconception), and check the failure notes.

### Step 1 — Mixed gate (3 drawn performances)
One story rep, one discovery segment, one plan section — unseen draws, scored.

**Expected output:** Scores recorded; the gate's weakest performance gets a Week 4 warm-up slot.

### Step 2 — Résumé claims audit
Line-by-line artefact mapping for the live résumé version.

**Expected output:** Audit table committed; zero untraceable bullets remain (rewritten or cut).

### Step 3 — Pipeline review
Applications by tier + stage; identify the 3 highest-value next applications (fit × evidence strength).

**Expected output:** Next-3 list committed with the fit argument per application.

### Step 4 — Pay down one debt item
Oldest debt item repaired with evidence.

**Expected output:** Debt log shrinks by one.

## Independent verification (checkpoint)
A frozen, audited story bank + a résumé with zero untraceable claims + a tiered pipeline with a named next-3.

## Unaided probe (closed-guide)
State your confidence (0–100%) before checking each answer.

1. Interleaved: three résumé bullets (yours, anonymised in the drill) — name the proving artefact for each, or flag it.
2. Teach-back: your pivot story ('why agentic AI, why now') in 90 seconds — it must use the bank, not biography clichés.
