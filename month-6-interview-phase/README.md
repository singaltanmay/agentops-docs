# Month 6 — Interview Phase

**Convert five months of evidence into offers.** Applications run from late
Month 5 in parallel; this month is the deliberate practice of interviewing
itself — same instructor model, new domain: timed drills, rubrics written before
performances, gaps classified and repaired by fresh probes, never by re-running
the failed item.

**Target tiers:** A — Agentic/Applied AI Engineer, FDE, Agent Platform roles at
AI-native companies and big-tech AI teams; B — FDE at labs/vendors; Stretch —
frontier Research Engineer (opportunistic). Standing filter: agentic-AI roles
only; the PERM 5-question screen gates external employers where it applies.
Realistic levelling (from the goal research): senior-track-but-new-domain —
argue level from scope evidence, anchor comp to dated, sourced bands.

Budget column: **≈$174** (system kept demo-ready through loop season).

## Month definition of done
- [ ] Frame card frozen; ≥4 full timed designs + 2 mini-designs, all scored against the frame rubric, with a visible weak-lens trend
- [ ] Three write-ups published (RAG ablations; evals + judge calibration incl. bias numbers; red-team before/after) + a portfolio index that reaches every artefact in ≤2 clicks
- [ ] Coding readiness measured screen-shaped (production rep + pattern recognition + trace diagnosis), with trace-debugging trend vs Week 2's first drill
- [ ] Story bank frozen: 8–10 STAR stories at two lengths, numbers-audited, mandatory coverage (win / failure / reversal / security / customer) complete; 8 behavioural reps with probe outcomes recorded
- [ ] FDE: discovery drill + brief-to-plan drill + one full chained simulation, all scored; the simulation's chain break named with a repair
- [ ] Résumé claims audit: zero untraceable bullets; application pipeline tiered and current; targeted wave executed with per-application requirement→artefact maps
- [ ] Two mock loops scored on the standing rubrics; merged gap list; final repair set (≤4) each verdicted by a fresh unaided probe
- [ ] Readiness sheet finalised and gate-backed (strengths, named open gaps with compensations, logistics verified — demo env up, links live)
- [ ] Negotiation pack: level case from scope evidence; comp figures all sourced + dated; trade/walk-away rules written before any offer exists
- [ ] Course retrospective committed (spend vs all six budget columns, judgement review, post-course backlog); PROGRESS.md closed out
